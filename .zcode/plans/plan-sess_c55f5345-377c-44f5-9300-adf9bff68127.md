# newui design-debt roadmap (full scope)

Each phase lands independently with `pnpm verify:affected` green. Ordered by (value ÷ risk).

## Phase 1 — Make the docs true again (no behavior change)
1. **CONTEXT.md**: fix `side` → `top | bottom | left | right`; document `violet` as a legal `theme` value (it ships in Badge/Avatar/KanbanBoard; `redesign-blueprint`'s "remove violet" was never executed — legalizing is cheaper than churning 3 components); document `bare` (Dialog) in `spec/dialog.md` or remove it; align `action`'s definition with the 3 real shapes.
2. **spec/form.md** + `FormControl.tsx` comment: TimePicker exists — wire/claim it instead of "not built yet".
3. **PRINCIPLES.md**: add the pre-1.0 clean-break exception to P13 (align with ADR-0013); reconcile "principle wins" with the `spec > ADRs > PRINCIPLES > CONTEXT` precedence chain; split the P14/P15 heading; fix `spec/README.md` `date-picker.md` → `datepicker.md`.
4. **Rewrite the definition-of-done** in AGENTS.md to match the real house pattern (single `<Name>.tsx`, shared `control-styles`/`tv` where variants exist, `.test.tsx`, browser test, story) — 72/73 components can't be wrong.
5. Move `spec/redesign-blueprint.md` + `spec/examples-refresh.md` → `spec/history/` (keep raw-glob compatibility: update `lib/specs.ts` glob + nav references); fix their stale claims only if kept in place.
6. `scripts/docs.ts`: prune deleted spec pages from `docs/` output.

## Phase 2 — API consistency + enforcement
7. **Unify single-select value shape to scalar** (pre-1.0, no consumers): `Select`, `FormControl` → `string | undefined` matching `Combobox`/`RadioGroup`/`Tabs`; `MultiSelect`/`ToggleGroup` stay arrays. Record in `spec/migrations.md`.
8. **TextInput**: accept native input attribute passthrough (like Button extends `JSX.HTMLAttributes`) — unblocks `autocomplete`/`inputMode`/`maxLength`.
9. `Select`/`MultiSelect`: import `popupFieldVariants` from `lib/control-styles.ts` instead of copy-pasted strings.
10. `ScrollTable`: stop exporting `TABLE_HEAD_CLASS`; `media.ts`: move `showDialog`/`closeDialog` to `lib/dialog/`; delete dead `scripts/port-icons.mjs`.
11. Add missing `data-slot` to the ~9 components lacking it (incl. Toast, Dropdown).
12. **Enforcement tests** (the repo's own pattern): a P4-vocabulary test (every `theme`/tone union in `api.json` ⊆ declared axes) and a CONTEXT-conformance test (props named `side`/`action`/`bare` match their CONTEXT definitions).

## Phase 3 — Package layering
13. Move `packages/atoms/src/lib/resource/` (18 Frappe-flavored files, currently `export *` from the atoms root) → `@newui/data` (query/form's declared home), re-point the starter/playground imports, keep atoms leaf-clean. Update AGENTS architecture table.

## Phase 4 — Token scales
14. Add **z-index scale** (`--z-base/raised/sticky/header/overlay/toast/tooltip`) + **motion tokens** (`--duration-fast/base/slow`, `--ease-*`) to `@theme`; replace hard-coded `z-50`×20 / `z-[100]`×4 / `duration-*` across components; extend `tokens.test.ts` discipline to them.

## Phase 5 — Missing components (each: spec + story + states + tests + classification + changeset)
15. **Typography atoms** `Heading`/`Text` (token scale already exists — the most-consumed gap).
16. **Semantic `Table`** primitive (`Table/Th/Tr/Td` slots) — the missing middle between ScrollTable and DataTable.
17. **`TagInput`** (Badge-based token input).
18. **`Stepper`** (wizard progress + step navigation).

## Phase 6 — Tests & harness breadth
19. Add missing tests: `ScrollTable` (zero today), browser tests for the 3 templates, ~10 organisms, ~7 molecules; a11y tests for the uncovered interactive set.
20. Playwright: add **WebKit + Firefox** projects; **touch emulation** for the mobile drawer + Kanban drag; keep Chromium as the budget/primary project.
21. Nightly cron workflow: stress/memory/dep-drift/`visual-review`; expand asserted visual baselines beyond the current 14 (all 12 app pages, light+dark, one width to start).

## Phase 7 — Release, CI, DX, site
22. **Cut the release**: run changeset version → first Version Packages PR → publish; add an `npm pack` + install-smoke CI job; `skill-versions` sync already exists.
23. CI: concurrency group (cancel superseded runs), artifact uploads (built site, lighthouse, coverage) on success, shard the 22-step checks job.
24. DX: `CONTRIBUTING.md`, PR/issue templates, and a **`pnpm gen component <name>`** scaffold (spec stub, story skeleton, `atomic.ts` entry, changeset — the exact steps conventions currently do by hand).
25. Docs site: `/changelog` page generated from changesets output + version in the masthead; "Edit this page" links.

**Decision points I've resolved with recommendations** (flag on review if you disagree): legalize `violet` rather than remove it; scalar single-select value API; `resource/` → `@newui/data` (not a new package); rewrite the definition-of-done rather than generate 73×4 files.
