# @newui/icons

Import individual Solid glyph components from `@newui/icons`. They render SVG
and accept the props declared by their shared icon factory. Keep decorative
glyphs hidden from assistive technology. Name an icon-only button on the button
itself. Avoid importing every glyph into a route; unused exports tree-shake.

The generated surface inventory lists every named glyph and its source. For
Lucide strings and dynamic components use Icon from @newui/ui.
