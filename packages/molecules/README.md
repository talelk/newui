# @talelk/newui-molecules

Compound controls and interactions assembled from atoms: fields, pickers,
menus, cards, overlays and selection controls.

```tsx
import { Dialog, Dropdown, Select } from '@talelk/newui-molecules'
```

The package depends downward on `@talelk/newui-atoms`. For application regions such as
filter bars, tables, sidebars and boards, use `@talelk/newui-organisms`.
